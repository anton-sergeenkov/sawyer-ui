# Usage

### Public

```ts
import { UiMenuItemGroup } from "sawyer-ui"
```

### Internal

```ts
import UiMenuItemGroup from "../../menu/UiMenuItemGroup"
```

### Usage

- Выпадающее меню — стандартный `Menu` Mantine, пункты — `Menu.Item`
- `type="routes"` — пункты-ссылки `next/link`, текущая страница (по `usePathname()`) выделена основным цветом темы Mantine
- `type="links"` — внешние ссылки, открываются в новой вкладке
- `theme` и `isAccent` задают вид кнопки, открывающей меню

```tsx
<UiMenuItemGroup
  type="routes"
  theme="light-blue"
  title="Menu"
  list={[
    { title: "About", path: "/about" },
    { title: "Contacts", path: "/contacts" },
  ]}
/>
```
