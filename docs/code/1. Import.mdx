# Import

## Common

Шрифт и стили пакета подключаются один раз, в корневом layout приложения:

```ts
import { robotoRegular } from "sawyer-ui/fonts"
import "sawyer-ui/styles.css"
```

```
<html lang="en" className={robotoRegular.className}>
```

## Components

```ts
import { UiButton, UiLayoutSection } from "sawyer-ui"
import type { IMenuItem, IStaticImageData } from "sawyer-ui"
```

## Fonts

Шрифты Roboto (next/font) — отдельная точка входа `sawyer-ui/fonts` без "use client",
поэтому их можно импортировать и в серверных компонентах (app/layout.tsx)

```ts
// Public
import { robotoThin, robotoLight, robotoRegular } from "sawyer-ui/fonts"
// Internal
import { robotoLight } from "../../fonts"
```

```
<span className={robotoThin.className}>Text</span>
```
